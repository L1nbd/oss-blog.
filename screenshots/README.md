## 二次开发效果验证

### 自定义主题（oss-blog-theme）
- 自定义导航栏：首页、技术、生活、数据库、关于
- 自定义文章卡片：包含封面图、标题、摘要、标签、发布时间
- 自定义404页面：友好的错误提示和返回首页链接
- 自定义页脚：包含版权信息、社交链接、技术栈说明

### 自主扩展功能
1. **相关文章推荐**：在文章详情页底部，基于当前文章标签匹配显示3篇相关文章
2. **阅读进度条**：在文章详情页顶部，随页面滚动实时更新阅读进度百分比

## 运行环境
- 操作系统：Windows 11
- Ghost版本：5.130.6
- Node.js版本：22 LTS
- 数据库：SQLite
- 访问地址：http://localhost:2368/
- 管理端：http://localhost:2368/ghost/
