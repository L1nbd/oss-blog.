# 自主扩展功能 Issue 列表

## Issue #1: 相关文章推荐功能

### 状态
已实现 ✅

### 用户故事
作为博客读者，我希望在阅读完一篇文章后，能够看到与当前文章主题相关的其他文章推荐，以便继续深入阅读感兴趣的内容。

### 验收条件
1. ✅ 文章详情页底部显示"相关推荐"区域
2. ✅ 基于当前文章的标签匹配相关文章
3. ✅ 最多显示 3 篇相关文章
4. ✅ 每篇相关文章显示标题、摘要、发布时间和标签
5. ✅ 如果没有相关文章，不显示推荐区域
6. ✅ 点击相关文章可跳转到对应文章详情页

### 实现方案
- 使用 Ghost 的 `{{#get}}` helper 查询相关文章
- 通过 `filter` 参数按标签过滤
- 排除当前文章
- 使用自定义样式渲染推荐卡片

### 实现文件
- `theme/oss-blog-theme/partials/related-posts.hbs` - 相关文章推荐 partial
- `theme/oss-blog-theme/post.hbs` - 引入相关文章推荐
- `theme/oss-blog-theme/assets/css/custom.css` - 相关推荐样式

## Issue #2: 文章阅读进度条

### 状态
已实现 ✅

### 用户故事
作为博客读者，我希望在阅读长文章时能够看到当前的阅读进度，以便了解还剩多少内容。

### 验收条件
1. ✅ 文章详情页顶部显示阅读进度条
2. ✅ 进度条随页面滚动实时更新
3. ✅ 进度条使用主题强调色
4. ✅ 仅在文章详情页显示，不在列表页显示

### 实现方案
- 使用 JavaScript 监听页面滚动事件
- 计算当前阅读位置占文章总长度的百分比
- 通过 CSS 动态更新进度条宽度

### 实现文件
- `theme/oss-blog-theme/default.hbs` - 添加进度条 HTML 和 JavaScript
- `theme/oss-blog-theme/assets/css/custom.css` - 进度条样式
