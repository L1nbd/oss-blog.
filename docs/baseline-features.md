## 2.4 基线已知限制

1. **邮件服务未配置**：默认 Direct 传输在本地环境可能无法发送邮件，影响会员注册/登录邮件、评论通知等
2. **会员登录为魔法链接**：Ghost 默认会员登录使用无密码魔法链接，非传统账号密码
3. **默认主题为 Casper**：基线使用官方默认主题，无自定义样式
4. **无演示数据**：基线仅含默认"Hello World"文章，无完整演示内容
5. **登录验证码**：Ghost 5.x 默认启用新设备登录验证码，需配置安全选项禁用
