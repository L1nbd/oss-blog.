# 《开源软件与新技术》实验报告

## 实验01：开源个人博客系统二次开发

---

## 一、实验需求

### 1.1 实验背景

个人博客系统包含身份、内容、分类、评论和检索等典型 Web 子系统，是观察开源软件生命周期的合适切入口。本实验要求以成熟开源项目为基线，完成可辨识的二次开发、测试、Git 版本管理和现场运行展示。

### 1.2 实验目标

1. 能够从 GitHub README、Release 和许可证中判断开源博客方案的适用边界
2. 掌握 Ghost 本地实例的安装、启动、停止、数据备份和故障检查方法
3. 能够定位主题、内容 API、标签和评论相关模块，并完成一项可见的二次开发
4. 完成注册/登录、文章、标签、评论和搜索主流程的功能测试
5. 掌握用 Issue、Feature Branch、Pull Request 和 Code Review 管理个人增量开发的方法

### 1.3 最终成品

独立交付并现场运行一个"可注册、可写作、可评论、可搜索的个人博客系统"，包含：
- 自定义主题
- 至少 1 项非换色类自主扩展功能
- 完整的测试记录
- Git 版本管理证据
- 完整的 README 文档
- 5-10 分钟 Live Demo

### 4.4 自主扩展功能

#### 4.4.1 功能1：相关文章推荐

**用户故事**：作为博客读者，我希望在阅读完一篇文章后，能够看到与当前文章主题相关的其他文章推荐，以便继续深入阅读感兴趣的内容。

**实现方式**：
- 使用 Ghost 的 `{{#get}}` helper 查询相关文章
- 通过 `filter` 参数按标签过滤
- 排除当前文章，最多显示 3 篇
- 自定义样式渲染推荐卡片

**文件**：
- `partials/related-posts.hbs`：相关文章推荐 partial
- `post.hbs`：引入相关文章推荐
- `assets/css/custom.css`：相关推荐样式

#### 4.4.2 功能2：阅读进度条

**用户故事**：作为博客读者，我希望在阅读长文章时能够看到当前的阅读进度，以便了解还剩多少内容。

**实现方式**：
- JavaScript 监听页面滚动事件
- 计算当前阅读位置占文章总长度的百分比
- 通过 CSS 动态更新进度条宽度
- 仅在文章详情页显示，不在列表页显示

**文件**：
- `default.hbs`：进度条 HTML 和 JavaScript
- `assets/css/custom.css`：进度条样式

## 七、遇到的问题与解决方法

### 7.1 Ghost CLI 安装失败

**问题**：`ghost install local` 失败，CLI 误检测到不存在的 `ghost@6.62.0`

**解决**：手动下载 Ghost 5.130.6 tgz 解压安装，建立 `current` junction

### 7.2 sqlite3 编译失败

**问题**：系统无 Visual Studio，sqlite3 源码编译失败

**解决**：从 GitHub releases 手动下载预编译二进制 `sqlite3-v5.1.7-napi-v3-win32-x64.tar.gz`，解压到 `node_modules/sqlite3/build/Release/`

### 7.3 express-hbs 路径问题

**问题**：Windows 上 `cacheLayout` 函数路径比较失败（相对路径 vs 绝对路径）

**解决**：手动修改 `node_modules/express-hbs/lib/hbs.js`，改用 `path.resolve()` 规范化后比较

### 7.4 登录验证码问题

**问题**：Ghost 5.x 默认启用新设备登录验证码，登录时需要输入邮箱验证码

**解决**：在 `config.development.json` 中设置 `security.staffDeviceVerification = false`，禁用登录验证码

### 7.5 邮件服务未配置

**问题**：Ghost 登录时尝试发送邮件，但本地环境无邮件服务

**解决**：启动本地假 SMTP 服务器（端口 2525），配置 Ghost 使用该 SMTP 服务器

### 7.6 登录次数锁定

**问题**：多次登录尝试触发暴力破解保护，显示"Too many different sign-in attempts"

**解决**：清除数据库 `brute` 表和 `sessions` 表，重启 Ghost

### 7.7 npm 依赖冲突

**问题**：postcss 版本与 cssnano 要求冲突

**解决**：使用 `--legacy-peer-deps` 参数安装依赖
